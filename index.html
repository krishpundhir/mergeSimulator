    Complexity

    Auxiliary space: O(1)

    Why? No temporary array is created. Only a constant number of variables (left, mid, i, right, count) are used, no matter how long the array is.

    The array itself is modified in-place.

    Time is a separate question

    O(1) describes extra memory, not running time. Swapping and shifting elements one position at a time can take quadratic time in the worst case, because an element may travel across many positions.
